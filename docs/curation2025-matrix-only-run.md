# Matrix-only chestnut RNA-seq run resolves in ENA, 2026-09-28

The earlier Supplementary Table 1 crosswalk found one matrix-only column, `SRR21681158`. A [live ENA run report](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=SRR21681158&result=read_run&fields=run_accession%2Csample_accession%2Csample_alias%2Csample_title%2Cstudy_accession%2Clibrary_strategy%2Cscientific_name&format=tsv) identifies it as a *Castanea mollissima* RNA-seq run, sample accession `SAMN30971621`, alias `Z90`, in study `PRJNA883560`. The [study report](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=PRJNA883560&result=read_run&fields=run_accession%2Csample_accession%2Csample_alias%2Csample_title%2Clibrary_strategy&format=tsv) lists 30 run IDs, and all 30 appear as columns in the distributed Figshare expression matrix. The table's suffix-different `SRR8383229` also resolves as an ENA run with alias `SHW-Gall-A2`, consistent with its matrix label. Exact source TSV bytes, checksums and replay checks are archived.

This strengthens the provenance of the matrix-only ID without explaining why the paper's sample annotation sheet omits it. A run accession is not itself proof of a distinct biological specimen or a valid matrix expression value. No raw reads were fetched and no gene-level, resistance, comparator or gate finding follows.
