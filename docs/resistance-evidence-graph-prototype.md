# Chestnut evidence graph: refusal before resistance attribution

This first prototype treats run, BioSample, project, species, variant-file label and blight phenotype as distinct typed nodes. It reuses the archived [213-column Figshare matrix](https://springernature.figshare.com/articles/dataset/Comprehensive_curation_and_validation_of_genomic_datasets_for_chestnut/27060067) and [SRA runinfo](https://trace.ncbi.nlm.nih.gov/Traces/sra-db-be/runinfo). Six predeclared regression cases show the mechanics. The three Z90 run columns collapse to one BioSample accession; the complete expression archive collapses 213 run labels to 180 BioSamples and includes four *C. sativa* columns. A cross-species pair fails a *C. mollissima*-only request, and a proposed `SZ_15` VCF-label-to-expression join fails because no VCF-label-to-BioSample crosswalk is established. **All six resistance-association requests abstain** because there is no verified per-BioSample blight phenotype label. A naive run-count tally would silently inflate the denominator and could suggest false replication.

The proposed new contribution is the task-specific refusal certificate tying these independent evidence conditions together, not a new graph algorithm. [BioSamples metadata standards](https://pmc.ncbi.nlm.nih.gov/articles/PMC8728232/) and [biomedical provenance graphs](https://pmc.ncbi.nlm.nih.gov/articles/PMC6800194/) are prior art. All scenarios were constructed after seeing the 213-run metadata, so the test is only a regression demo; no prospective comparator, genotype-expression association, phenotype result, independent discovery or gate credit. A future source-grounded phenotype crosswalk and untouched evaluation set would be required before any resistance claim.
