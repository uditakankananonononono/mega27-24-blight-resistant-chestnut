# Infection-cohort file index: full 30-URL availability check, 2026-09-27

The prior run-route audit HEAD-checked one of thirty advertised FASTQ URLs from the [third-party SeqOut index](https://seqout.org/api/project/CRA006690/runs/download) for the Chinese chestnut early-infection cohort. This follow-up HEAD-checked **all 30** advertised file URLs on the primary download host: every one returned HTTP 200 with a Content-Length exactly equal to the index's advertised byte count, totaling **74,578,217,301 bytes** across 15 paired runs. The 30 advertised MD5 values are distinct and well-formed. The archived check record, index hash, replay script and hermetic test are in this repo.

This is availability and size-agreement evidence only. HEAD metadata does not prove the files contain the study's reads, are uncorrupted, or will remain available; MD5s were not verified against content because no payload bytes were downloaded. The primary GSA browse route still does not serve this fetcher, so the index remains a secondary-source lead. No accession dataset was fetched-and-used, no expression or resistance result follows, and no service/accession/derivation/page gate credit is claimed.
