# Chestnut Figshare VCF header union, 2026-09-28

The [2025 chestnut curation paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC12103606/) reports 330 resequencing samples. The [linked Figshare dataset](https://springernature.figshare.com/articles/dataset/Comprehensive_curation_and_validation_of_genomic_datasets_for_chestnut/27060067) contains two aggregate VCFs and 98 per-label VCF file entries. This audit fetched only bytes 0-65535 of each aggregate VCF via the Figshare download URLs in its API (file IDs 49310671 and 49310698), recorded the returned ranges `bytes 0-65535/107745150` and `bytes 0-65535/1479393912`, and archived the exact 65,536-byte prefixes. They are *partial BGZF streams*, not complete VCFs. The script decompresses only the first gzip member and extracts its `#CHROM` header, never interpreting variant calls.

The GBS173 header has 173 unique sample-column labels; the RS60 header has 61. Figshare per-label filename metadata supplies 97 unique labels from 98 files (`SM_20` repeats as a filename label). There is no GBS/RS60 or GBS/per-file overlap; RS60 and the per-file labels overlap at `SZ_15`. The union is therefore **173 + 61 + 97 - 1 = 330 distinct VCF manifest labels**. `scripts/audit_curation2025_vcf_header_union.py` verifies the counts and archives all labels and source-range checksums in `results/curation2025_vcf_header_union.json`. This narrows the formerly unresolved 330 count to a reproducible Figshare *label inventory* correspondence, not an independently validated 330 biological-sample ledger. The separate [ENA study report](curation2025-study-sample-scope.md) contains 737 sample accession labels; a mapping from its records to these VCF labels has not been established.

No full aggregate VCF or per-label VCF was fetched, and no genotype, phenotype, accession payload, fair comparator or new discovery was assessed. Zero project-gate credit is claimed.
