# Chestnut expression archive species-label screen, 2026-09-28

The [2025 multi-*Castanea* resource article](https://pmc.ncbi.nlm.nih.gov/articles/PMC12103606/) distributes [213 run-labeled expression matrix columns](https://springernature.figshare.com/articles/dataset/Comprehensive_curation_and_validation_of_genomic_datasets_for_chestnut/27060067). Replaying the archived [SRA runinfo](https://trace.ncbi.nlm.nih.gov/Traces/sra-db-be/runinfo) against all columns gives **209 labeled *Castanea mollissima* and four labeled *Castanea sativa***. The four are `SRR8305472` through `SRR8305475`, all in PRJNA509688, each a distinct BioSample accession. The authors' Supplementary Table 1 identifies all four as full-budburst bud samples: two Madonna and two Bouche de Betizac. This source crosswalk prevents a reader from using all 213 columns as a homogeneous *C. mollissima*-only cohort without species filtering or modeling.

The article itself covers several *Castanea* species, so these four are not an article error. SRA taxonomy is an archive label, not a genetic ancestry assay; the cultivar names should not be treated as independent genotypes or trees. This does not connect expression to blight phenotypes or make a resistance discovery. The replay script checks archived runinfo rows and supplement XLSX independently of the earlier 213-column JSON; its test pins counts, IDs and source hashes. No underlying reads were downloaded and no project gate credit follows.
