# Linked study has 737 ENA sample accessions, not a 330-record article crosswalk, 2026-09-28

A fuller live [ENA report for PRJNA540917](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=PRJNA540917&result=read_run&fields=run_accession%2Csample_accession%2Csample_title%2Clibrary_strategy&format=tsv) lists 737 run records with **737 distinct sample accession labels**. The archive's library strategy labels divide into 522 WGA, 214 WGS and one Hi-C. This corrects the preceding narrower audit: the run-to-sample relation *is* available from this source after requesting the additional columns. But these 737 project-level records cannot be equated with the [2025 article's](https://pmc.ncbi.nlm.nih.gov/articles/PMC12103606/) curated set of **330 resequencing samples** without an inclusion manifest or article-level mapping. The strategy metadata alone does not say which records entered the curation; the fact that 737 distinct ENA labels exceed 330 is not a paper error. No read payloads or genotype records were individually fetched or used; zero gate credit.
