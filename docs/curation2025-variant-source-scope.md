# Chestnut resequencing count denominators, 2026-09-28

The [2025 chestnut curation article](https://pmc.ncbi.nlm.nih.gov/articles/PMC12103606/) prints **330 resequencing samples**. An archived [ENA run report for PRJNA540917](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=PRJNA540917&result=read_run&fields=run_accession&format=tsv) lists 737 distinct run accessions; the [linked Figshare manifest](https://springernature.figshare.com/articles/dataset/Comprehensive_curation_and_validation_of_genomic_datasets_for_chestnut/27060067) has 98 per-label variant VCF file entries and 97 distinct filename labels. These are three different units. A specimen can have multiple runs and aggregate VCFs may contain multiple samples; the archived run report has **no sample_accession column** and the VCF contents were not fetched. Consequently neither 737 nor 97 can corroborate or contradict the paper's 330-sample claim. This is a count-denominator warning, not read or variant analysis. No accession-payload, comparator, discovery or gate credit.
