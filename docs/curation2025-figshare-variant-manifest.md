# Figshare variant file manifest, 2026-09-28

The [2025 chestnut data paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC12103606/) states that its curation contains 330 resequencing samples. The [linked Figshare dataset](https://springernature.figshare.com/articles/dataset/Comprehensive_curation_and_validation_of_genomic_datasets_for_chestnut/27060067) lists 102 files in its live API metadata. Of these, 98 filenames follow the `variant_data_PRJNA540917_<label>_QL.vcf.gz` pattern, representing 97 unique filename labels: `SM_20` occurs twice. The other four objects are a genome annotation tarball, expression ZIP and two aggregate variant VCFs. The 98 per-label file count is not a 330-sample provenance ledger; aggregate VCFs may contain additional samples, but this audit did not download the multi-gigabyte VCF contents. A duplicate **filename label** is not evidence of a duplicated biological specimen. This is file-inventory QC only, not 98 individually analyzed accession payloads, an independent discovery or project gate credit.
