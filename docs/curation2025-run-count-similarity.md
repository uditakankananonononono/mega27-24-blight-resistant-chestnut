# Chestnut archived processed counts: repeated-run similarity, 2026-09-28

We [froze the comparison](../prereg/2026-09-28-run-versus-biosample-count-similarity.md) before opening processed count values. The [Figshare archive](https://springernature.figshare.com/articles/dataset/Comprehensive_curation_and_validation_of_genomic_datasets_for_chestnut/27060067) has 33,991 gene rows in each of three count matrices. The exact source ZIP MD5 and SHA-256 were verified before extracting those three matrix members. Using Pearson correlation of log(1+count), the replay compares run-column pairs **only within the same BioProject and matrix layout**, classifying pairs by equal versus different SRA BioSample labels.

The PE matrix yields 40 same-BioSample pairs and 1,866 different-BioSample pairs. PRJNA883560, the largest repeated-sample group, has 30 same-sample pairs (median 0.98662) and 405 different-sample pairs (median 0.94031), a descriptive median gap +0.04631. PRJNA786529 has six versus nine pairs (medians 0.99122 versus 0.93028); PRJNA562370 has two versus four (0.92854 versus 0.93236), so a uniform same-sample advantage is **not** claimed. PRJNA573571 has two equal-BioSample pairs with correlation 1.0, and both same-BioSample pairs have **exactly equal counts at all 33,991 gene rows** (library sums 23,779,843 and 28,593,865, respectively). This is an observed duplicate processed-count vector, not proof of why those separate run labels share values. Its different-BioSample median was 0.98785. SE has no same-BioSample pair; the six SS run columns all map to one BioSample, yielding 15 same-sample pairs but no within-study other-sample comparator (median 0.82798). Per-project quartiles and source hashes are stored in the JSON.

This is processed-count quality/context for a database-unit audit, not blight resistance or evidence of 180 different trees. Correlations are dependent pairs and no p-value is assigned. Distinct count columns, even highly correlated, do not become independent biological replicates. We did not individually fetch 213 underlying FASTQ payloads. The replay script, three extracted archived matrix members and test are included. There is no comparator win, biological discovery, or project gate credit.
