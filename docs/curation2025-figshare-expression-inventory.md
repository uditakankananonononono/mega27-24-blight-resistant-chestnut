# Figshare expression archive inventory, 2026-09-28

The [2025 chestnut data paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC12103606/) prints 213 RNA-Seq samples. The [linked Figshare dataset](https://springernature.figshare.com/articles/dataset/Comprehensive_curation_and_validation_of_genomic_datasets_for_chestnut/27060067) has 102 files. Its `gene_expression.zip` was downloaded from the [dataset file endpoint](https://ndownloader.figshare.com/files/49310509) and matched the public Figshare MD5 `34132bf8c0f62cdc30fda9537ef30d06`; the archive SHA-256 is pinned in JSON. The 25 MB archive is not committed, but its extracted first-line headers are preserved with a script that audits those archived headers and a hermetic test.

Raw count matrices have 156 PE, 51 SE and 6 SS sample columns, totaling 213 distinct SRR-labelled columns. The FPKM matrix and correlation matrix each also contain those same 213 distinct column identifiers. This closes the prior narrow question of whether the paper's printed 213 expression columns exist in the distributed Figshare archive. It does **not** reconcile why the four GEO series cited in the paper's text list only 32 samples, nor prove the archive columns correspond to 213 independent people or independently assess expression values. The eight `other` reference matrices each have 11 columns and are listed separately, not added to the 213. No individual accession-payload, comparator, discovery, derivation or paper-page gate credit claimed.
