# Chestnut expression archive: 213 run columns and 180 BioSample labels, 2026-09-28

The [2025 chestnut resource article](https://pmc.ncbi.nlm.nih.gov/articles/PMC12103606/) describes 213 RNA-seq "samples." Its [distributed Figshare expression matrix](https://springernature.figshare.com/articles/dataset/Comprehensive_curation_and_validation_of_genomic_datasets_for_chestnut/27060067) indeed has **213 different SRR-labeled columns**. To check the biological-sample *database unit*, we froze the complete 213-label set and analysis rules in `prereg/2026-09-28-expression-sample-unit-audit.md` before fetching [NCBI SRA runinfo](https://trace.ncbi.nlm.nih.gov/Traces/sra-db-be/runinfo). Eleven archived CSV responses cover all 213/213 exact SRR prefixes with no unresolved IDs. They map to **180 distinct BioSample accession labels**, not 213 independent BioSample labels. The run/BioSample multiplicity is 163 accessions with one run, four with two, 12 with three and one with six. By matrix layout, 156 PE columns map to 128 BioSamples, 51 SE columns map to 51, and six SS columns map to just **one BioSample**. None is shared across those three layouts.

The previously audited `Z90` example (three run columns, one accession `SAMN30971621`) is one of the 12 triple-run records. A separate SS study contributes all six SS columns under one accession `SAMN32254054`; no disease phenotype or biological independence follows from this metadata. A sample accession is not necessarily a different tree or experimental unit, and a distinct count column is not necessarily an independent biological replicate. Conversely, the article's 213 count is valid *as a distributed column/run count*; this audit should not declare the article erroneous without its intended unit definition. The complete run crosswalk, per-study counts, source hashes and replay test are in this repo. NCBI runinfo consists of metadata only; no underlying FASTQ payload was fetched, no resistance association or held-out benchmark was run, and **no C24 gate credit** is claimed.
