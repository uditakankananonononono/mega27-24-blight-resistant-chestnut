# Chestnut Supplementary Table 1 versus expression-matrix sample columns, 2026-09-28

The [2025 curation paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC12103606/) states that its RNA-seq expression resource has 213 samples. Its [Supplementary Table 1 XLSX](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC12103606/supplementaryFiles) lists **212 distinct SRR ID rows**, while the [Figshare expression matrix](https://springernature.figshare.com/articles/dataset/Comprehensive_curation_and_validation_of_genomic_datasets_for_chestnut/27060067) has **213 sample columns**. Exact label comparison shows the table's `SRR8383229` as `SRR8383229_SHW_Gall_A2` in the matrix, and the matrix's bare `SRR21681158` has no Table S1 row. After mapping just the unambiguous SRR-prefix suffix, the 212 table IDs are all represented, with that one matrix-only run ID. The paper's 213 count agrees with the distributed matrix but the printed sample annotation table does not fully annotate that matrix.

This is a reproducible metadata crosswalk from original supplementary XLSX and previously archived Figshare matrix headers, with SHA-256s and row IDs in `results/curation2025_supplement_expression_crosswalk.json`. It does not explain the omission or decide whether the matrix-only run should have been excluded. It does not fetch RNA-seq read payloads, prove a biological difference, establish a fair comparator/discovery or earn project gate credit.
