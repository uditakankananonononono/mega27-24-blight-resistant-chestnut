# Frozen prototype question before six scenario evaluations

Make an accession-aware evidence graph that treats run, BioSample, project, species and phenotype as different nodes. Input the published 213-column SRA crosswalk and the separate curated-VCF label inventory. For a requested run set, report run/BioSample/species/project counts; label same-BioSample pairs; refuse a C. mollissima-only cohort when any SRA species label differs; refuse resistance discovery when no per-BioSample blight phenotype link exists; refuse genotype-expression integration without a verified link from VCF header label to BioSample. Six predeclared tests: (1) Z90 three runs one BioSample, (2) two other repeated runs one BioSample, (3) mixed-species pair, (4) two distinct same-species BioSamples without phenotype, (5) full 213 expression columns, (6) GBS-to-expression bridge absent. Compare a naive count-the-run-columns and presume-phenotype rule only as a deliberately invalid negative control; these scenarios are constructed from already inspected metadata, not a held-out benchmark. The graph is a task-specific typed validation prototype, not an assertion of algorithmic novelty or biological resistance finding. First audit prior art on sample ontologies/evidence graphs before any originality claim.
