# Frozen before count values: same-BioSample run similarity

Question: Are repeated run-labeled columns attached to one NCBI BioSample generally more alike than different-BioSample columns within the same BioProject and matrix layout? This is processing/source-unit QC, not phenotype biology. Source is previously authenticated Figshare expression ZIP, archived header, 213-run crosswalk. Within each raw-count matrix (PE/SE/SS), keep all nonnegative integer genes; use Pearson correlation of log1p(count) across all shared rows. Before seeing any pairwise values, form all run pairs within BioProject/layout; classify same versus different BioSample accession. Summarize counts and full distribution (min, median, max, quartiles) per category, per project. Primary descriptive contrast is median within-sample minus median between-sample for PE projects having both pair types; no p-value, because pair dependencies and processing details are unresolved. Include SE/SS eligibility and source hashes. Stop if matrix/header/zip checksum fails. No run is called a biological replicate and no accession payload gate or discovery credit follows. This is an audit of processed Figshare values, not FASTQ reads.
