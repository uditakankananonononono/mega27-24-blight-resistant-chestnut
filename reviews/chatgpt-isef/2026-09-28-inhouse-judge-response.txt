Verified positives

The project has identified a real curation/annotation discrepancy: the expression matrix contains 213 SRR-labeled columns while the original supplementary table contains 212 unique SRR rows, with SRR21681158 traceable to C. mollissima, sample SAMN30971621/Z90 and sharing that biological sample accession with two other runs.

The reported sibling-run correlations (~0.981–0.988) are useful evidence that the extra column is not, by itself, proof of a spurious biological sample. The packet appropriately treats this primarily as a run-to-sample annotation problem.

The 330 distinct deposited variant-label strings are a legitimate manifest reconciliation, but the packet correctly does not equate them with 330 independent, phenotype-labeled resistance samples.

Replayed scripts, provenance checks, headers, count-unit checks, and manifest crosswalks constitute useful data-audit infrastructure.

Most importantly, the project is currently making appropriately bounded claims: the packet does not manufacture a resistance gene, benchmark victory, or biological discovery from the curation discrepancies.

Bottom line on the last gate

The cleanest nomination is:

For independently sampled chestnut specimens, measure infection/disease severity under a predefined blinded scoring scheme and collect matched molecular measurements from the same specimens, then test whether the prespecified molecular signal tracks observed disease severity.

That is an observational measurement, not a construct-design experiment. It would provide the missing biological bridge between the project's computational audit and an actual resistance-associated phenotype.

Material weaknesses

Run count is being kept separate from biological sample count — correctly, but the project has not yet solved the sample-unit problem.
Fix: produce a complete run → sample accession → individual/line/genotype → phenotype crosswalk, with explicit rules for repeated runs.

The matrix-only SRR is interesting but not a discovery of resistance biology.
Fix: demonstrate a prespecified biological phenotype association using independently identifiable specimens.

The 330 VCF labels are not a resistance cohort.
Fix: map each usable variant sample to biological accession and phenotype, retaining only records whose identity and phenotype provenance can actually be established.

No strongest published baseline has been operationalized.
Fix: preregister one precise prediction task, identify the strongest genuinely comparable published method/model, freeze preprocessing and evaluation, then run both under identical conditions.

There is no independent same-task validation.
Fix: partition an independently sourced, phenotype-annotated cohort before model selection/tuning and lock it completely until final evaluation.

The project has not reached the claimed research-service/tool threshold.

The manuscript/evidence gate remains incomplete.

Fresh prespecified published-data pivot

A strong pivot without retroactively tuning a failed hypothesis would be:

Chestnut disease-severity concordance audit

Freeze before looking at the outcome:
Define disease severity as the dependent variable and predefine one molecular measurement family—e.g. expression-derived aggregate signal or a prespecified published resistance-associated feature set.

Then:

Select a published-data cohort whose biological samples and disease/severity labels can be independently mapped.

Establish the accession/sample/phenotype crosswalk before molecular association testing.

Keep repeated sequencing runs nested within their biological sample rather than treating runs as independent observations.

Predefine the statistical test and covariates.

Test whether the molecular measurement differs monotonically or otherwise systematically with the published disease-severity phenotype.

Hold out a genuinely independent published cohort if one can be established.

Report the result whether positive, null, or contradictory.

Crucially, the SRR21681158 discrepancy should not determine the hypothesis. It can remain a separate reproducibility/curation result. The biological test should be defined from the phenotype question first.

If no adequately linked phenotype cohort can be established, the correct outcome is not to manufacture one from the 213/330 counts; the project should remain a data-resource audit rather than claiming a resistance discovery.

Overall readiness

Current ISEF-style readiness: NOT READY for a biological-discovery claim.

The project has a credible data-audit foundation and at least one concrete, reproducible curation finding. But the central scientific gates—new biological discovery, fair benchmark comparison, and independent frozen phenotype validation—are presently failures, not near-passes.

The most defensible competition framing at this stage is therefore “published chestnut genomic-data provenance/curation audit with a proposed phenotype-linked validation analysis,” rather than “new chestnut blight-resistance discovery.”

The decisive next evidence is not more manifest counting. It is a predefined phenotype-linked analysis on correctly resolved biological sample units, followed by genuinely independent frozen validation
